# Otvoreni-Skup-Podataka 1.0
Otvoreni skup podataka Izrađen u svrhu prve laboratorijske vježbe iz predmeta Otvoreno Računarstvo na Fakultetu Elektrotehnike i Računarstva Sveučilišta u Zagrebu

Skup podataka je storen u alatu MongoDB na hrvatskom i engleskom jeziku te dijeljen u skladu sa licencom Creative Commons 1.0 Universal

Skup podataka izradio je Ivan Lovrinović

Podatci sadržani u skupu bit će artikli u dućanu sa audio opremom.

Oblik podataka:

kolekcija: brands
  atributi:
    ID
    name

kolekcija: categories
  atributi:
    ID
    name
    
kolekcija: products
  atributi:
    ID
    brandID
    catID
    name
    price
    features
